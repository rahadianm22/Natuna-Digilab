# antislop audit 001, 2026-10-02

Scope: every page and shared component in `src/`, plus README.
Owner instruction: fix everything without asking, take design decisions autonomously.

## Design Read

Reading this as: documentation site for a design system, for Indonesian product designers and
front-end engineers, in a calm editorial-docs language anchored on the Natuna Foundation tokens
(Azure Blue, Slate Gray, Urbanist), dial ENERGY 2 / RHYTHM 2 / MOTION 1.

Direction source: the Natuna Foundation Figma file already mapped in `globals.css`, plus the logo
supplied by the owner. No new palette or typeface is introduced.

Reference survey (structure only, nothing copied visually): Carbon, GOV.UK Design System,
Atlassian Design, GitHub Primer. Patterns adopted because they serve readers of a design system:

- honest lifecycle label on every component, tied to a single source of truth
- "On this page" navigation on long pages
- live example with a code tab and a copy button
- Do and Don't side by side, not stacked
- an accessibility section per component
- related components at the end of a page
- breadcrumb that reflects the real hierarchy

## Decisions

- Status is derived from the tracker for every component that appears in it. Components that are
  not in the tracker keep their documented status and are marked "Not tracked" so the source is visible.
- The npm package is described as not published. Code snippets are labelled "Proposed API".
- Templates leave the main nav. The route stays and says plainly that no templates are published.
- Identity motif: real Natuna components composed into Indonesian product screens (a transfer form,
  a bill card), shown wherever a decorative visual would otherwise go.
- One accent: Azure Blue 700 for links and the single primary action per screen.
- Motion: hover and focus transitions only (MOTION 1).
